# Student Portal → Колледж оқу процесін басқару жүйесі

## Іске қосу (XAMPP)
1. Apache мен MySQL іске қосыңыз.
2. `student-portal` папкасын `htdocs` ішіне көшіріңіз (бұрынғы `css/style.css` мен `images/` резервке сақтаңыз — CSS жаңартылды).
3. phpMyAdmin → Import → `database.sql` (бар `users` деректері сақталады, `role`/`status` бағандары қосылады; бұрынғы пайдаланушылар студент болады).
4. `db.php` ішінде MySQL логин/парольді тексеріңіз.
5. Браузерде `http://localhost/student-portal/setup.php` ашып әкімшіні жасаңыз, сосын `setup.php` файлын жойыңыз.
6. Кіру: `http://localhost/student-portal/login.php`

## Алғашқы қадамдар (әкімші ретінде)
Топтар → Пәндер → Пайдаланушылар (немесе студент/мұғалім өздері тіркеледі) → Мұғалім тағайындау → Сабақ кестесі.

## Құрылым
- `admin/` — әкімші: панель, пайдаланушылар, пәндер, топтар, тағайындау, кесте, бағалар, тапсырмалар, журнал
- `teacher/` — мұғалім: кабинет, бағалар, тапсырмалар, кесте
- `student/` — студент: кабинет, бағалар, тапсырмалар, кесте
- `submissions.php`, `download.php`, `notifications.php`, `profile.php` — ортақ беттер
- `storage/` — жүктелген файлдар (`.htaccess` арқылы жабық, тек `download.php` береді)
